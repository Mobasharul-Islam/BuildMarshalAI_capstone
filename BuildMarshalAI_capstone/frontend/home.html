Grounded answers

Answers you can check, down to the page

Marshal finds evidence by looking at your pages, not only reading their text — each page image is embedded, so a table on a drawing sheet is found as readily as a sentence. Every answer shows the pages it used, ranked, so you can open the evidence and judge it yourself.

  • Source pages with every answer
  • Tables, drawings and scans understood visually
  • Search one project or the whole workspace
  • Ask by voice, reviewed before it is sent
  • Mail and Drive files indexed alongside uploads
  • Rate the evidence to flag a weak answer

Records from a sentence

Say it once. Marshal builds the record

Ask for a project, a task, a user or a cost. Marshal reads what you gave it, asks only for the mandatory fields still missing, and keeps every answer across messages. When nothing is left to ask, it opens the finished form for review — nothing is created before you press Create.

  • Projects, tasks, users, roles and costs
  • Asks for what is missing — never invents it
  • Remembers answers across messages
  • Links only to records that really exist
  • Whole projects onboarded from their documents
  • Drafts reviewed before anything goes live

Project health

Know where the project stands

Statistics are computed from the tasks, costs and procurement Marshal already holds, so the dashboard, the report and the assistant always quote the same numbers. Earned value follows the fixed-formula 50/50 rule; flow metrics show how fast work actually moves.

  • Earned value — SPI, CPI and the S-curve
  • Budget against committed procurement
  • Throughput and cycle-time trends
  • Overdue and long-lead risk flags
  • Phase read from the work itself
  • To-do lists mailed to the roles you pick
